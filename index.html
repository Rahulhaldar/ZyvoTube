FAQ

Questions, answered.

What is ZyvoTube?

ZyvoTube is a modern Android video client focused on discovery, playback, Shorts and supported downloads.

Does ZyvoTube support Shorts?

Yes. Shorts has a dedicated vertical feed with continuation and playback features.

Can I play videos in the background?

Background playback is supported where the current media and device allow it.

Where can I get the APK?

The latest release is published through the project's GitHub Releases page.
